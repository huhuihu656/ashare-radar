# 设计：极简趋势简报 + 财富感首屏

- 日期：2026-11-07
- 状态：待评审
- 决策人：用户

## 1. 背景与目标

信号已收敛为唯一的「清晰上升趋势」（2026-11-06 线上 37 只），但前端仍是多信号时代的结构：英雄区口号、4 张 KPI 卡、左侧信号筛选栏、居中详情弹窗。这些装饰与已删除的 12 个信号一起失去了意义。

用户要求：

1. **重新设计整体前端**；
2. 方向选 **A 极简趋势简报**——单列榜单，行内嵌 60 日迷你走势线；
3. **进站即要有「发财」的视觉感受**，强度选 **浓郁**。

成功标准：

1. 首屏 1 秒内传达「今天有 37 只、平均涨了多少、哪只最好」；
2. 每行的 60 日趋势形状肉眼可判，无需点开；
3. 页面比现在明显更轻：无英雄区、无 KPI 卡、无左栏、无弹窗；
4. 金色/红色的情绪层不损害可读性与专业感（不出现赌博式视觉）。

## 2. 信息架构

```text
┌────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 · 板块▾ · 搜索 · 档案▾ · 刷新                     │ 56px sticky
├────────────────────────────────────────────────────────────┤
│ 财富带：日期 + 「N 只清晰上升趋势」                           │ ~170px
│         平均60日涨幅（红） · 平均趋势效率 · 最高分（金）        │
├────────────────────────────────────────────────────────────┤
│ 榜单：表头（可排序）+ 37 行                                   │
│   #  标的  60日走势  ER  60日涨幅  最大回撤  距MA20  涨停  分数 │
│   点击行 → 原地展开详情（同时只开一行）                        │
├────────────────────────────────────────────────────────────┤
│ 页脚：研究预警声明                                            │
└────────────────────────────────────────────────────────────┘
```

**删除**：英雄区（口号/CTA）、4 张 KPI 卡、左侧筛选栏、居中模态框。
**迁移到顶栏**：板块筛选、搜索、历史档案、刷新。
**详情改为行内展开**：不再使用模态框。

## 3. 视觉系统

### 3.1 色板

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#05080f` | 页面底色 |
| `--bg-2` | `#080d18` | 财富带底色 |
| `--surface` | `#0b1220` | 行/展开面板底色 |
| `--line` | `rgba(230,180,80,0.14)` | 金色发丝分隔线 |
| `--ink` | `#f2f5fb` | 主文字 |
| `--muted` | `#93a1b8` | 次要文字 |
| `--quiet` | `#66748c` | 弱化文字 |
| `--gold` | `#e6b450` | 金色主调 |
| `--gold-bright` | `#ffd479` | 金色高亮/分数 |
| `--gold-soft` | `rgba(230,180,80,0.12)` | 悬停/面积填充 |
| `--up` | `#ff4d5e` | 上涨（A 股红） |
| `--down` | `#2fbf8f` | 下跌/回撤 |
| `--score` | `#ffd479` | 分数 |

**约束**：金色只用于「财富带、走势线、TOP1、高分」，正文与次要指标一律中性色。红色只用于涨幅与正值。禁止大面积金红渐变边框。

### 3.2 财富带

- 高度约 170px（桌面），移动端自动增高并纵向堆叠。
- 背景：`radial-gradient(120% 140% at 88% -20%, rgba(230,180,80,0.22) 0%, rgba(230,180,80,0.06) 38%, transparent 62%)` 叠在 `--bg-2` 上。
- 左侧：`as_of` 日期（28px，`--gold-bright`，等宽）+ 副标题「清晰上升趋势 · N 只」（`--muted`）。
- 右侧：三组大数字，标签在下：
  - 平均 60 日涨幅（`--up`，带 `+`）
  - 平均趋势效率（`--gold-bright`，3 位小数）
  - 最高分（`--gold-bright`，1 位小数）
- 底部：1px 金色渐变发丝线（`transparent → --gold → transparent`）。
- 三个数字入场时从 0 滚动到目标值（见 4.4）。

### 3.3 榜单

- 使用语义化 `<table>`，`<thead>` sticky 于顶栏下方。
- 列（桌面）：`# | 标的 | 60日走势 | ER | 60日涨幅 | 最大回撤 | 距MA20 | 涨停 | 分数`
- 行高 56px；行间 1px `--line` 发丝线；悬停背景 `--gold-soft` 的 40% 不透明度。
- **TOP 1**：左侧 2px 金色竖条 + 名称前 `TOP 1` 金色徽章。
- 分数 ≥80 用 `--gold-bright`，其余用 `--ink`。
- 涨幅带 `+` 号并用 `--up`；回撤用 `--down`。
- 涨停数为 0 时显示为 `0`（不以红色强调）。

### 3.4 迷你走势线

- 内联 SVG，尺寸 `160 × 36`（桌面），数据取 `klines.json` 的 `series.day` 末 60 根收盘价。
- 折线：`--gold`，1.5px，`stroke-linejoin="round"`。
- 面积：金色垂直渐变（`rgba(230,180,80,0.28)` → `transparent`）。
- ER < 0.25 时折线改用 `#8a7a55`（暗金），面积透明度减半——让「更直的线更亮」。
- 数据不足 2 根时不画并留空，不报错。

### 3.5 展开面板

- 展开行下方插入一个横跨全宽的 `<tr><td colspan=9>` 面板。
- 顶部 1px 金色发丝线；背景 `--surface`；内边距 20px。
- 内容顺序：
  1. 日/周/月 K 线切换 + 图表（复用现有渲染逻辑，改为容器内渲染）
  2. 买卖点四行：买入参考价（含触发状态）、止损价、止盈价（1:N）、计划依据
  3. 指标明细：ER、60 日涨幅、最大回撤、距 MA20、MA20/MA60、涨停次数、结构（低点/高点是否抬高）
  4. 参考仓位与依据
  5. 主力资金（若有）
- 同时只允许一行展开；再次点击同一行收起。

### 3.6 字体与排版

- 数字统一 `font-variant-numeric: tabular-nums`，使用等宽栈。
- 榜单正文 14px；指标 13px；分数 16px/700；财富带数字 40px/700。
- 中文使用现有系统字体栈，不引入外部字体（保持离线可用）。

## 4. 交互

### 4.1 排序

- 表头可点击排序列：ER、60 日涨幅、最大回撤、距 MA20、分数。
- 默认按分数降序；再次点击同列切换升/降序；排序状态在表头用金色箭头标识。

### 4.2 展开/收起

- 点击行任意位置切换；键盘 `Enter`/`Space` 同效。
- `Esc` 收起当前展开行。
- `↑`/`↓` 在行间移动焦点（roving tabindex）。
- 展开时若已有其他行展开，先收起再展开新行。

### 4.3 顶栏

- 板块下拉：全部 / 主板 / 创业板 / 科创板 / 北交所。
- 搜索：按代码或名称即时过滤。
- 档案下拉：读取 `docs/data/archive/index.json` 的日期列表；切换后加载对应 `archive/<day>.json`；处于历史模式时显示「返回最新」。
- 刷新：重新拉取 `latest.json`（带 cache-busting）。

### 4.4 动效

| 元素 | 效果 | 时长/缓动 |
|---|---|---|
| 财富带数字 | 从 0 滚动到目标值 | 900ms，ease-out |
| 榜单行入场 | 透明度 0→1，位移 8px→0，按行错峰 20ms | 320ms，前 20 行 |
| 走势线 | `stroke-dashoffset` 描边绘制 | 600ms |
| 悬停/展开 | 背景与边框过渡 | 120ms |
| 展开面板 | 高度展开 + 淡入 | 220ms |

- `prefers-reduced-motion: reduce` 时：关闭计数、错峰、描边与高度动画，直接呈现最终状态。

## 5. 响应式

| 断点 | 行为 |
|---|---|
| ≥1100px | 全部列 |
| 900–1100px | 隐藏「距MA20」「涨停」列 |
| <900px | 隐藏走势线与次要指标，仅保留 #、标的、ER、涨幅、分数 |
| <700px | 财富带改为纵向堆叠；顶栏控件换行 |

## 6. 数据契约

**不新增任何后端字段**，只使用现有数据：

- `latest.json` / `archive/<day>.json`：`as_of, universe_count, coverage, signal_counts, signals[]`
- 每行读取：`symbol, name, board, close, er, gain_60_pct, mdd_pct, ext_pct, limit_ups, higher_lows, higher_highs, ma20, ma60, score, entry_price, stop_loss, take_profit, risk_reward, entry_state, plan_note, position_pct, position_tier, position_reason, mf_date, net_mf_amount`
- `klines.json`：`stocks[symbol].series.day`（末 60 根用于走势线，全部用于展开后图表）

财富带聚合值在前端计算：

- 平均 60 日涨幅 = `signals` 的 `gain_60_pct` 算术平均
- 平均趋势效率 = `er` 算术平均
- 最高分 = `score` 最大值

## 9. 风险

| 风险 | 说明 | 处置 |
|---|---|---|
| 金色过量显得廉价/像博彩 | 用户明确要「发财感」，但过度会损害可信度 | 金光透明度上限 0.22；金色只用于指定元素；正文保持中性 |
| 动效拖慢感知 | 37 行同时入场可能卡顿 | 只对前 20 行做错峰；其余直接显示 |
| 展开面板替换模态框后 K 线尺寸变化 | 现有渲染函数按弹窗尺寸绘制 | 展开时按容器宽度重绘；切换日/周/月时重绘 |
| 红色在 A 股语义正确但易与「风险」混淆 | 涨幅用红是本地惯例 | 回撤用绿，形成对照；页脚保留研究免责声明 |
| 深色 + 金色在低亮度屏幕对比不足 | 金色在暗底对比度尚可 | 正文不使用金色；关键数字加 `text-shadow` 微弱发光但不影响可读 |

## 10. 验收标准

1. 首屏无需滚动即可看到财富带与至少 8 行榜单
2. 榜单默认按分数降序，TOP1 有金色标识
3. 每条走势线能肉眼分辨趋势方向与平滑度
4. 展开面板包含 K 线、买卖点、指标明细、仓位与资金流
5. 断网/数据缺失时不白屏，显示明确的空状态
6. 页脚保留「研究预警，不构成投资建议」
